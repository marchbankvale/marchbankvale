Install it in Gmail

  1. Press Copy signature above.
  2. In Gmail: Settings (gear) → See all settings → General.
  3. Scroll to Signature → Create new → name it Marchbank & Vale.
  4. Click into the box and paste (Cmd + V).
  5. Set both dropdowns — For new emails use and On reply/forward use — to it.
  6. Save Changes at the bottom.

If you send from more than one address, Gmail keeps a separate signature per address — repeat for each one you actually send from.
